# FIT 桌面 0.3.0 車機驗收

本版保留免費 OpenFreeMap 及主畫面的左右分區：左側即時地圖，右側播放器與捷徑。導航預設全螢幕；系統左右視窗屬實驗功能，位置與比例仍由車機決定。

## 自動定位

在設定允許精確定位，並開啟車機系統 GPS。取得有效 GPS 後，左側標記目前車輛位置並跟隨；不要求車輛先有速度。拖動地圖會切換自由瀏覽，按「回到目前位置」恢復跟隨。超過 10 秒未取得新定位時移除舊標記並顯示定位中。GPS、底圖載入與地址查詢是三個獨立狀態；底圖與地址服務可能需要網路。

## 播放器驗收（必須在車機進行）

KKBOX、官方 YT Music、Morphe Music 各測一次。從實際安裝清單依套件名稱區分，勿把後兩者當成同一 App。

1. 選「固定播放器」，播放歌曲。核對卡片播放器名稱、歌名、播放／暫停、上一首／下一首，以及重新檢測報告的套件與 actions。
2. 暫停指定播放器，在另一個 App 播放；固定模式仍控制指定來源。
3. 切換「跟隨目前播放」：指定來源播放時優先控制指定來源；指定來源暫停時跟隨另一個播放中的來源。
4. 在跟隨來源按暫停，卡片保留該工作階段供恢復播放。另一來源開始播放時可切換；啟動時不選無關的舊暫停工作階段。
5. 缺少媒體控制的按鈕應停用；歌詞標示「歌詞功能尚未提供」，不視為授權錯誤。
6. 到手動檢查相應播放器項目，先按「開始本項測試」保存當時情境，測完再記結果與備註。

## 人工結果與歷史

結果分為正常、有問題、待測試、不適用、資訊、歷史結果。人工記錄保存項目、結果、開始時間、App 版本、情境、備註。開始後改變預設桌面、播放器或其他相關設定，結果會保留為歷史，顯示本情境待測試。回到原情境可顯示原情境的最近結果。

從 0.2.1 升級後，舊正常結果不能增加本版正常數量。無版本／情境的舊記錄也只能列為歷史。倒車影像須在 FIT 為預設桌面時開始測試；其他桌面情境不能標成本情境正常。125% 字體本身是環境資訊，實際裁字請在可讀性測試記錄。

## 熄火測試

1. 停車後按「開始熄火測試」；開始時間、uptime、開機計數與情境會保存。
2. 熄火後再發動，進入手動檢查按「完成測試」。
3. 檢查開機觀察，再分別確認畫面、音樂、GPS 是否恢復，保存備註。

相同開機計數只代表仍是同一次開機，不能證明曾休眠，也不能代表恢復正常。缺少任何人工確認時不列正常。

## 自動回歸範圍

單元測試涵蓋來源選擇、舊版本／不同情境、開機比對、GPS 新鮮度與左右窗格尺寸。Android 測試涵蓋歷史結果持久化及 125% 字體主畫面。這些不能代替實車音樂控制、倒車影像、GPS 收訊、熄火與車機系統分割測試。
