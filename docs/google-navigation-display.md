# Google導航顯示與導航王快捷（0.4.24）

Google模式中，桌面維持原免費定位地圖，上方固定Google導航通知區。底圖顯示定位，不包含Google或導航王的路線/轉彎圖層。完整Google路線請按開啟導航，或使用原系統分割介面。

提示區在Google模式中保持位置/高度，通知未到、斷線、結束或過期都不會把整張地圖換成另一畫面。8秒未有新文字時不繼續顯示舊方向/距離，而顯示過期提示；沒有把舊通知重新掃描當成新收到。
通知重掃移除先清空狀態，改先組完整有效快照再一次發布；同key空白更新僅保留既有文字與原時間。實車閃爍原因尚未透過事件時間線確證，這是修正可見的程式閃爍來源，須實車驗收。

選Google後，地圖下方可直接按「導航王」。使用實際可啟動App清單，使用者0.4.22實車已確認套件com.kingwaytek.a5i_3d.plus；若有多個候選或其他版本，先讓使用者選擇，不猜私有入口。選擇成功切換導航綁定並開啟導航王；Google正在進行的行程要自行結束。返回Google用更多→Google導航。

驗收：停車開始Google導航，返回桌面，看底圖持續存在、提示在上方更新。比較提示新鮮/過期/導航結束時，底圖不應突然換成整頁通知。按導航王驗證實際開啟及綁定，再回Google。回報通知是否仍過早消失/閃爍、道路標籤/定位是否正常，以及快捷開啟結果。截圖不必包含其他通知或帳號資訊。
不將模擬器測試當實車閃爍已修復，不把免費定位底圖稱為Google完整地圖。
