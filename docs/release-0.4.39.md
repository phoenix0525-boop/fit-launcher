# 車機桌面 0.4.39（46）：修正發動後不自動續播

- 修正：FYT 熄火時會先暫停播放器再關螢幕，原本這個暫停被當成「使用者手動暫停」而取消續播資格；現在關螢幕或關機前 15 秒內、且不是在桌面按的暫停，發動後仍會續播。
- 修正：播放器在喚醒後重建工作階段時常先回報「暫停」，原本會直接取消這次續播；現在不再因此取消。
- 修正：續播不再要求開啟系統服務（無障礙）。原本系統服務未開、被系統關掉或尚未收到前景時，續播會一直等待到 60 秒後放棄；現在只有確定倒車／相機畫面在前景時才等待。
- 其餘維持 0.4.38：只對上次實際播放的同一播放器送出最多一次播放；不使用全域媒體鍵、不強制開啟已被系統關閉的播放器、不切換畫面。
- 測試目標：愛客思 AKZ ZX09／UNISOC UIS7870SC／FYT-SYU／Android 13；尚未完成實車驗收。正式版本只接受既有 B693…DD8 憑證。
