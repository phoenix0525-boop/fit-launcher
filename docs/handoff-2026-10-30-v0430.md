## 驗證與限制

本機無 Android SDK／Gradle 快取，未在本機編譯 APK。七項 Python 專案檢查與 git diff --check 通過。已新增／更新單元與 UI 回歸，GitHub Actions 自動建置、單元及模擬器結果請以分支最新 SHA 的 checks 為準；交接文件不把執行中視為通過。Android 13 UI 基準為 2000×1200／240dpi／字體 1.25；另有 API29 分割視窗回歸。

本版未完成原廠實際音量控制、導航 App 嵌入、方向盤協議、DSP 自動寫入、ACC 喚醒驗收。沒有發布 Release 或線上更新。

## 原廠韌體靜態證據

已驗證解壓後 launcher、ms、us、SystemUI APK 的大小與 ZIP CRC，檢查 manifest 與 dex 指令。

- 原廠 launcher `com.syu.launcher` 透過 TaskView／WMShell 將 App 畫面嵌入指定 Rect；含系統 task 權限與 shared UID。一般第三方桌面不能據此假設獲授相同能力。
- 音量呼叫鏈：SoundController module 4 → command 0 → IRemoteModule.cmd。降低為 [-2]、增加為 [-1]、絕對值 0..36。這只是反組譯所得，尚未從本 App 連接或發送。
- Remote 預設服務 action `com.syu.ms.toolkit`、package `com.syu.ms`，實際 ToolkitService 存在；Binder 內部授權與實車可用性未確認。
- 原廠音量鍵可使實際聲音變小，但 Android MUSIC 可一直 36。小芳測試有暫停／靜音干擾；不能把所有取樣變化當音量成功。
- 完整分析：https://drive.google.com/file/d/1N2bJnQAw_wxPV5AbJFVkLdU7kaquGxEU/view

## DSP 參數

使用者說可沿用先前提供的參數，但目前可核實的對話中找不到完整數值表，不能聲稱已恢復舊參數。照片可確認：前左右聲道高通 62Hz／12dB/oct、低通直通、Loud 關閉，EQ Q 顯示3.2。各頻段增益沒有數字，勿以曲線像素當精確增益。原廠 EQ APK 尚未分析，未實作自動套用。下一步先確認讀回、備份、還原與實機套用，再考慮啟動自動套用。

請實際檢查並修正 Bug、操作不順與排版問題，重點如下：

1. 設定分類是否符合使用者找設定的順序；切換後捲動歸零、返回、狀態保存與重建有沒有錯亂。檢查天氣授權碼輸入、外觀、亮度排程的狀態是否意外丟失或互相覆寫。

3. 運動風／動感風：完整日夜配色、主文字及次要文字對比、停用圖示、桌布／封面合成背景、舊設定與匯出匯入相容性。保留其他風格及角色隱藏流程。

5. 原廠 DSP 入口不存在、被停用或無法開啟時不得崩潰；音量檢測入口須正確。使用原廠獨立 App，不複製其整套 UI。

7. 原廠 Binder 音量、TaskView 導航嵌入與 DSP 自動套用先做權限、協議與讀回可行性分析，標註證據與限制，不憑字串或 manifest 宣稱可用，不直接發送未驗證硬體命令。
