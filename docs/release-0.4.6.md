車機桌面 0.4.6

- 每日自動檢查正式新版，可關閉；有新版時顯示提示，由使用者下載與確認安裝。
- 下載驗證 SHA-256、套件、版本與既有正式簽章；不接受舊測試版作為自動更新。
- 附近地址優先顯示服務回傳的完整門牌；無門牌時保留路段，不推算或保證住戶位置。
- 記住最後實際播放的播放器，重新啟動桌面／喚醒時優先接回其既有媒體工作階段。
- 播放器已被系統關閉時，可點「連接上次播放器」重新開啟；能否自動續播由播放器決定。
- 保留 0.4.5 地圖平滑跟隨、車速縮放、圖示捷徑、音量控制與可選系統分割入口。

- 可選 LRCLIB 桌面歌詞，需使用者明確啟用後才會送出歌曲資訊查詢；有時間碼且播放器提供進度時才逐行同步。
