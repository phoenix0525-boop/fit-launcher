# 車機音量對照檢測

這是收集差異的工具，不是原廠音量修復。小芳能調聲、桌面無效是使用者回報，未由本工具實測證明。

## 操作
停車、保持同一播放器與同一首音樂播放，用原廠按鍵設定舒適的音量，勿在通話或導航語音播報中比較。
到設定 → 實機檢測 → 音量檢測。每項單獨操作：
1. 桌面絕對設定：降低一格，記錄調整前、約150/600/1500ms後的Android數值。
2. 桌面相對調整：降低一格，與絕對設定分開比較。
3. 小芳／小方：20秒觀察，開始後說「你好小芳，小聲一點」，只用小芳調整一次。
4. 原廠按鍵：20秒觀察，開始後按原廠降低音量鍵一次。與方向盤鍵分開測，必要時重新觀察並在回報時說明按的是哪個鍵。
每項完成後選「有變小／沒有變化／不確定」。工具不自動調回音量，以免覆寫小芳或原廠按鍵後續操作；需要時自行調回舒適音量。切換檢測分頁/離開組合畫面取消當次任務；程序被殺不會補造結果。進入頁面不會自動測試。
到匯出報告 → 存到下載資料夾；提供產生的FIT實機檢測文字檔。不要另上傳錄音或帳號資料。

## 可以判斷的範圍
| 觀察 | 可得結論 | 不能推斷 |
|---|---|---|
| fixed=true | Android回報固定音量政策 | 小芳或原廠硬體一定不能調音 |
| 桌面送出後數值未變 | 這次公開媒體音量方法未得到目標回讀 | 一定缺權限、MCU故障或小芳用了哪個私有介面 |
| 曾到目標又變回 | 取樣顯示Android數值回復 | 由哪個程序改回 |
| 數值有變、使用者說聲音沒變 | 兩種證據不一致，需比較播放來源與原廠路徑 | 原廠音量已修復 |
| 小芳改聲、所有可見Android流都未變 | 使用者聲音回報與公開Android數值不同 | 已證實某個MCU/FYT命令 |
| 小芳改聲且某個流有變 | 找到可繼續驗證的相關數值 | 該流一定是控制原廠擴大機的唯一方式 |
輸出裝置類型只是可用輸出清單，不是目前播放路由。時間為本次測試相對經過時間；觀察期間若混用按鍵、App或音樂來源，報告不能歸因。

## 語音擴充方向
保留小芳既有的實車音量能力；桌面現有語音辨識處理台灣導航、選定播放器及桌面指令。小芳是否能把辨識結果交回桌面、或直接啟動聆聽，仍需公開介面證據。只開到「車助理設置」不能視為喚醒成功。
不修改或複製第三方APK，不使用猜測的MCU/FYT、私有廣播或ADB常駐權限。先取回對照報告，再決定是否增加可驗證的公開控制方式。

Android官方參考：https://developer.android.com/reference/android/media/AudioManager （isVolumeFixed、getStreamVolume、setStreamVolume、adjustStreamVolume、getDevices）。
