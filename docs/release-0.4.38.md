# 車機桌面 0.4.38（45）

本版沿用 0.4.37 機甲主題與 0.4.36 的一次性續播機制，只補上要求的開機預設與無歌詞顯示，不更換播放器控制架構。

- 新安裝或尚未設定時，開機自動連接上次播放器與自動續播預設開啟；既有明確關閉的選擇仍保留。
- 續播來源固定為上次實際播放的播放器，等待 3 秒後才判斷；只對相同 MediaSession 發送最多一次 `ACTION_PLAY`。
- 其他播放器已播放、使用者手動操作、通話、已辨識倒車畫面或音訊尚未就緒時不重複發送播放指令。
- LRCLIB 確認無同步或文字歌詞時，在原歌詞區顯示機甲能量柱；查詢中及有歌詞時維持原畫面。
- 能量柱是播放狀態驅動的裝飾動畫，不擷取音訊；最高 30 FPS，暫停、停止或離開畫面時停止更新。
- 不新增錄音、背景定位、懸浮窗或其他權限；不使用全域媒體鍵，不強制啟動已被系統關閉的播放器 App。
- 即時地址、導航、地圖尺寸、原有機甲素材、主題設定、亮度排程、專輯封面 fallback 與播放器手動控制均保留。

播放器被 Android 關閉、沒有可控制的 MediaSession，或播放器因登入、網路、背景限制拒絕播放時，仍需手動開啟／連接播放器。

測試目標：愛客思 AKZ ZX09／UNISOC UIS7870SC／FYT-SYU／Android 13。其他機種可能不相容，且本版本尚未完成實車驗收。

正式版本只接受既有 B693…DD8 憑證；未簽署輸出不能當作正式更新安裝或發布。
