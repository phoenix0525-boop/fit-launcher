# FIT 桌面功能整合規格（草案）

- 日期：2026-10-25
- 狀態：待使用者確認，尚未進入程式修改
- 預定版本：v0.2.0
- 主程式套件：`tw.fitcar.launcher`

## 1. 目標

以現有「FIT 桌面」的 Honda FIT4 日系原廠風格、KKBOX、亮度排程、App 綁定與實機檢測為主體，獨立重做「開車趣」中適合本專案的測速、路況、語音與駕駛輔助功能。

成功條件：

1. 支援 Android 12 以上，`minSdk = 31`、`compileSdk = 36`、`targetSdk = 36`。
2. 保留 Home 啟動器、全螢幕所有 App、2×2 捷徑、導航分割畫面退路、KKBOX MediaSession、亮度排程及返回原廠桌面。
3. 加入可單獨開關的 GPS 測速提醒、固定測速點、區間測速資料框架、國道路況、按鍵式語音控制與 TTS。
4. 不以模擬資料冒充實際功能；資料未載入、定位未完成、來源不支援時顯示明確狀態。
5. 使用 FIT 桌面自有長期憑證；更新版可覆蓋安裝上一個正式簽章版本。
6. 不修改、不重簽、不內嵌 `carhome-public.apk`，不複製其程式碼、圖像、文字排版或簽章。

## 2. 技術基線

- Kotlin、Jetpack Compose
- Android 12（API 31）以上
- Google Play 2026 新 App 要求：target API 36
- 套件名稱維持 `tw.fitcar.launcher`
- 裝置方向以 2000×1200 橫向為主，支援比例與字體縮放
- 不依賴 root、FYT、MCU、韌體修改或未公開系統 API

## 3. 功能範圍

### 3.1 保留並完成現有 FIT 桌面

- 日間／夜間 Honda 風格主畫面。
- 「所有 App」全螢幕 App 抽屜與搜尋。
- 每頁四格、2×2 自訂捷徑；更換、移除、排序及重新啟動保留。
- 導航 App、音樂 App、測速 App 均由使用者從實際安裝清單綁定，不猜套件名稱。
- 導航分割畫面優先，失敗退回全螢幕。
- KKBOX／其他播放器透過 Android MediaSession 顯示曲目、封面、播放狀態與可用控制。
- 沒有合法歌詞來源時，不擷取或假造歌詞，保留「開啟 KKBOX」入口。
- 日間／黃昏／夜間亮度排程與正式 `WRITE_SETTINGS` 授權。
- GPS 車速明確標示資料來源。
- 設定內固定保留返回原廠桌面及實機檢測。

### 3.2 新增測速提醒

- 由使用者主動開啟「行車提醒」，以前景服務取得 GPS。
- 固定測速資料優先使用警政署政府開放資料，下載後離線保存並顯示資料日期。
- 依行進方向、距離與定位精度篩選前方測速點；資料不足時不報假警示。
- 提醒方式：畫面卡片、提示音或 Android TTS；三者可分別關閉。
- 國道與一般道路的預告距離可調整。
- 定位中斷時顯示「GPS 訊號中斷，測速提醒暫停」。
- 區間測速只有取得具授權且含起終點、方向、速限的可靠資料後才啟用；第一個增量先建立資料介面與停用狀態，不自行猜測區間。

### 3.3 新增國道路況

- 只連接有正式使用條款的政府開放介面。
- 顯示／朗讀前方事故、施工、封閉與壅塞；需能關閉語音。
- 網路不可用時維持桌面和離線測速，不反覆重試耗電。
- 若資料介面需要申請金鑰，金鑰只能由本機 Secrets／GitHub Secrets 注入，不寫入原始碼。

### 3.4 新增語音控制

- 採按鍵後才開始辨識，不做持續偷聽或背景錄音。
- 使用 Android `SpeechRecognizer` 與 `TextToSpeech`；麥克風拒絕授權時其他功能照常可用。
- 第一版命令白名單：
  - 開啟已綁定導航 App。
  - 導航回家／公司／指定地點（僅在目標導航 App 支援標準 Intent 時）。
  - 開啟 YouTube、KKBOX 或使用者指定 App。
  - 報時、朗讀目前 GPS 車速。
  - 詢問前方是否有已載入資料中的測速點。
- 不自動送出訊息、不輸入帳密、不使用未公開第三方介面。

### 3.5 浮動提醒與地圖互切

- 第一選擇為 App 內卡片與 Android 通知，不要求無障礙服務。
- 若實機確認導航全螢幕時確有浮動提醒需求，第二階段再評估 `SYSTEM_ALERT_WINDOW`；預設關閉並由使用者到系統頁手動允許。
- 不用無障礙服務讀取畫面內容、模擬點擊或追蹤輸入。
- 導航轉彎資訊只在選定導航 App 公開通知可合法取得時顯示；否則由原導航 App 自己呈現。

### 3.6 雙指音量手勢

- 先保留目前實機檢測：雙指上滑、雙指下滑、單／雙指雙擊。
- 若原車機系統層手勢仍有效，不重複攔截。
- 若實機證明只在原廠桌面有效，再於 FIT 桌面加入局部手勢：上滑增音量、下滑減音量、雙擊靜音。
- 不建立全域無障礙手勢攔截。

## 4. Google Play 與更新策略

- 不使用 `QUERY_ALL_PACKAGES`；維持 `MAIN/LAUNCHER` 與明確 `<queries>`。
- 不使用 `REQUEST_INSTALL_PACKAGES`，不做網站下載 APK 後自我更新。
- Google Play 版以 AAB 上傳內部測試；另產生同憑證 Release APK 供 ADB 備援。
- 背景定位、前景服務、通知、麥克風均採功能需要時才詢問，拒絕後可繼續使用桌面。
- 上架前完成資料安全表、隱私權政策、前景服務及背景定位用途檢查。

## 5. 自有憑證

- 沿用既有 `fit-launcher-release.p12` 與別名 `fitlauncher`，不得建立第二把發行金鑰。
- 憑證與 Base64 內容不得加入 Git、APK、AAB、公開壓縮檔或日誌。
- GitHub Actions 僅由 Secrets 還原暫存金鑰，簽完立即刪除。
- 正式包須驗證：非 debug、v2/v3 簽章有效、憑證 SHA-256 與專案紀錄一致。
- 金鑰遺失將導致無法以同套件名稱覆蓋更新，必須另做離線備份。

## 6. 安全與隱私邊界

### 一律執行

- 將網路下載的 JSON／CSV 視為不可信輸入，限制大小、逾時、欄位與座標範圍。
- 顯示資料來源、資料日期與免責提醒。
- 位置、住家／公司地址與捷徑只存在車機本機。
- 所有敏感功能提供主開關、狀態與撤銷入口。
- 行駛中避免複雜設定操作與長文字彈窗。

### 實作前需再次確認

- 需要 API 金鑰或付費帳號的路況／地圖 SDK。
- 使用浮動視窗或背景位置。
- 新增任何會提高 Google Play 審查風險的敏感權限。

### 絕不執行

- 不複製或修改第三方 APK。
- 不繞過 Google Play Protect、進階保護或第三方 App 授權。
- 不上傳即時位置、麥克風錄音、帳密或裝置唯一識別碼。
- 不宣稱 GPS／開放資料可取代現場道路標誌。

## 7. 開發增量與驗收

### 增量 A：平台與簽章基線

- 將 minSdk 改為 31、compileSdk／targetSdk 改為 36。
- 更新版本至 v0.2.0。
- 建立 Release APK 與 AAB，驗證正式憑證與沒有秘密檔案進產物。
- 驗收：單元測試、Debug／Release 編譯、APK Manifest 與簽章檢查通過。

### 增量 B：離線固定測速

- 先寫距離、方位、速限、重複提醒抑制及錯誤資料測試。
- 完成資料匯入、離線快取、GPS 前景服務與 UI 狀態。
- 驗收：模擬路線測試通過；沒有定位或資料過期時不產生假警示。

### 增量 C：TTS 與語音命令

- 先寫命令解析白名單測試。
- 完成按鍵式語音辨識、TTS 與授權拒絕退路。
- 驗收：不授權麥克風仍可正常作為桌面；未知命令不執行外部動作。

### 增量 D：國道路況

- 確定官方介面與授權後才實作。
- 驗收：網路中斷不影響桌面／離線測速；回應異常時安全降級。

### 增量 E：實機限定功能

- 車機在場後測試導航通知、浮動提醒、雙指音量、倒車影像、休眠喚醒、方向盤鍵。
- 只有實測通過的能力才從「實驗性」改為正式功能。

## 8. 建置命令

```powershell
.\gradlew.bat testDebugUnitTest
.\gradlew.bat assembleDebug
.\gradlew.bat bundleRelease
.\gradlew.bat assembleRelease
```

本機沒有 Android SDK／JDK 時，使用 GitHub Actions 執行相同測試與建置；建置成功不等於車機實測通過。
