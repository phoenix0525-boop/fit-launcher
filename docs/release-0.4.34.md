# 車機桌面 0.4.34／41：設定重新分類、音量改用原廠、自動開啟統一判斷

- 設定改為「日常／初次設定／維護／診斷」四群 11 類：導航 App 在「導航」選、播放器在「音樂與音效」選、捷徑獨立一頁；啟動設定與返回原廠桌面合併為「桌面接管」；實機資訊併入實機檢測；備份與更新合併。
- 定位、通知存取等權限在用到的分類就地顯示；「權限總覽」集中列出狀態。
- 主畫面音量鈕改為說明與原廠入口（方向盤音量鍵、原廠語音助手、原廠音效），不再顯示 Android 音量數值或送出音量指令；實車已確認桌面音量指令不會改變聲音。
- 開機、系統服務補開、螢幕喚醒、原廠桌面切回改用同一套判斷：倒車／相機畫面在前景時不開啟，同一次開機只開一次，開機後已在使用其他 App 時不拉回。
- 設定頁的桌面接管狀態只在回到前景與切換開關時更新，不再每 2 秒輪詢。
- 角色主題隱藏入口改為連點「關於」五下。
- 開發候選版本，尚待實車驗收；不自動發布線上更新，正式憑證 B693…DD8 不變。
