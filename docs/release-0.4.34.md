# 車機桌面 0.4.34 候選版（尚未發布）

## 已修改
- Google 導航通知與免費定位底圖改成上下獨立區域，避免原生地圖遮住轉彎文字；提示區高度依內容調整，保留通知缺少／過期說明，不偽造轉彎資訊。
- 新增 125% 字體版面回歸斷言：地圖與提示的矩形不得重疊。
- 原廠嵌入檢測改成「直接 TaskView 路徑受限、原廠橋接未驗證」，不再由缺少單一權限推論所有嵌入方式都不可行。

## 原廠音量調查
本次重新下載並分析原廠 SystemUI.apk，已找到下拉音量滑桿的聲音模組呼叫及音量／靜音回呼代碼，詳見 systemui-volume-investigation-v0434.md。桌面目前仍使用 Android stream 控制，尚未接通原廠 Binder；不能宣稱音量已修好。
