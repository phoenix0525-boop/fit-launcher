車機桌面 0.4.16

修正
- 開導航王或其他 App 後回到桌面，夜間「桌面調暗」會確實恢復。
- 夜間開機時沒有網路：不再整晚卡在亮色地圖；網路恢復後自動重試深色底圖，按「重試載入」也會重試深色。
- 匯出設定改從主題清單自動產生，新增主題不會讓匯出失敗；手動亮度覆寫不再被備份或還原。
- 調暗滑桿放開才儲存；匯入預覽改在背景計算。

介面
- 地圖下方只留「開啟導航」、回家／去公司與「更多」；縮放與回到定位浮在地圖右下角，地圖變大。
- 播放鍵 64 dp、其他控制 56 dp（小螢幕維持 48 dp）。
- 主畫面不再放被卡片擋住的大角色圖，只保留時鐘旁小圖。
- 蜘蛛人夜間改中灰藍，仍是淺色系但較不刺眼。
- 「詞」改為「歌詞」按鈕；進度條改為細條，不再有尾端紅點，停車時點一下可調整。
- 空捷徑格改為虛線框＋「＋」；沒有圖示的 App 顯示通用圖示。
- 行車中隱藏狀態小標籤；未授權定位時「目前位置」縮成一行，點一下即可允許。
- 所有 App：不顯示套件名稱、名稱加大、可搜尋（停車時）、列出最近使用。
- 「關於」只列最近 3 版，其餘收進「更早版本」；設定分類依常用順序排列。
- 超速提醒改用橘色，與紅色按鈕區分；整理為 5 級字級。
