# 車機桌面 0.4.35／42：Shizuku 一鍵授權、停用原廠桌面、自動開啟修正

> **測試機型：愛客思 AKZ ZX09（UNISOC UIS7870SC 晶片，FYT／SYU 原廠系統，Android 13，2000×1200），裝於 Honda FIT4 2022 油電版。**
> 其他機種、晶片或原廠系統可能有相容性問題，請先執行「實機檢測」，不要直接設為預設桌面或停用原廠桌面。

- 新增「一鍵授權（Shizuku）」：使用者自行安裝並以無線偵錯啟動 Shizuku 後，一個按鈕完成通知存取、浮動視窗、使用情況、修改系統設定、背景執行、定位、附近裝置、系統服務（無障礙）與預設桌面，不必再用電腦手打 adb 指令；授權重開機後仍有效。「原廠切回」「喚醒開啟」等開關仍由使用者決定。
- 新增「系統服務被關閉時自動恢復」：已授權時，App 更新或當掉後若系統關掉無障礙服務，開機或回到桌面時自動重新開啟（只在使用者開啟相關功能時）。
- 新增「停用原廠桌面（進階）」：車機桌面已是預設桌面且 Shizuku 可用時，可停用原廠桌面，讓 Home 與開機只進車機桌面；可隨時還原，並顯示電腦還原指令。不列入設定、系統介面與最近使用畫面提供者。
- 修正：開機廣播的開啟請求被系統擋下時，誤記為「本次開機已開過」，導致系統服務不補開。
- 修正：開機後校時造成同一次開機被誤判為兩次（改用系統開機次數）。
- 修正：熄火喚醒時把導航中的畫面拉回桌面；導航 App 在前景時不開啟。
- 修正：開機初期狀態列、輸入法、原廠服務提示被誤判為「正在使用其他 App」而不補開。
- 實機資訊新增「最近前景切換」（只在記憶體，最多 10 筆），可確認倒車畫面與原廠桌面的實際名稱；說明文字與小字字級整理。
- 開發候選版本，尚待實車驗收；不自動發布線上更新，正式憑證 B693…DD8 不變。
