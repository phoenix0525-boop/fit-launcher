- 顯示與亮度、App 綁定、導航、權限、啟動設定及原廠桌面頁新增對應測試入口。
- 手動檢查可直接開啟 Google 地圖、導航王、已綁定的對應播放器、測速 App、語音及系統設定；不自動改綁定或接管開關。
- 新增喚醒與小工具檢查；提供亮度、GPS、分割、按鍵與音量只讀檢測快捷。
