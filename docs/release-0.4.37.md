# 車機桌面 0.4.37（44）

新增「設定 → 主題 → 機甲」，可直接選擇，不需要解鎖其他角色主題。

設定入口統一為「主題」，選一套即可套用整體外觀與建議配色；配色、插畫、面板透明度收進預設折疊的「主題細節」。舊設定值保留，收起不會重設微調；舊「外觀與配色」入口仍可導向新頁面。機甲面板固定不透明，只提供適用的小插畫開關。

- 石墨黑面板、切角外框、少量工業斜紋；紫綠時鐘小像、橘白音樂卡及紅黑捷徑卡。
- 三台機甲為重新生成的原創插畫素材，不剪貼原始模型照片。素材為三格透明 PNG，僅渲染在原有標題區。
- 地圖不放角色、不新增角色側欄，內部 padding、寬高權重與工具列尺寸維持原樣。
- 四尺寸與行車模式測試比對原主題及機甲主題的地圖邊界，並確認插畫不與地圖重疊，主要觸控鍵至少 48 dp。
- 小螢幕自動隱藏部分裝飾；「顯示小插畫」開關可關閉。機甲主題不使用全版人物背景，避免遮住資訊。
- 沿用 0.4.36 的上車自動續播功能，預設關閉。

機甲配色在日間與夜間皆使用深色面板，仍保留日夜排程與背光設定；強調色可另外調整。

測試目標：愛客思 AKZ ZX09／UNISOC UIS7870SC／FYT-SYU／Android 13。其他機種可能有相容性問題，尚未完成實車驗收。

正式憑證維持 B693…DD8；未簽署 Release 須先由使用者在本機簽署後才能正式安裝／發布。
