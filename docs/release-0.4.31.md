# 車機桌面 0.4.31／38：設定、配色與檢測判定修正

- 從實機檢測或選擇 App 返回設定時，保留原本分類、捲動位置與尚未儲存的天氣授權碼；從桌面重新開啟設定才回到第一頁。切換分類仍從頁首開始，選取的分類會自動捲到可見位置。
- 狀態文字（已允許／有問題）在所有風格與日夜都至少 4.5:1；修正蜘蛛人夜間狀態字幾乎看不見的問題。
- 音量檢測以實際聽感判定：桌面送出控制但聲音沒變會列為「有問題」；未回報或不確定列為待測；Android 數值不變不再被說成「沒有作用」。
- 報告在仍有待測項目時，不再只寫「沒有問題」。
- 切換播放器等情境只讓相關檢測變成待測，已驗證的背光、導航等結果保留。
- 原廠 DSP／EQ 入口先檢查是否存在、停用或可開啟；新增原廠整合可行性只讀檢查（不連接、不送命令）。
- 「關於」分開列出適用條件、已回報實測機型（AKZ ZX09）與待驗證功能。
- 開發候選版本，尚待本版實車驗收；不自動發布線上更新，正式簽章策略不變。
